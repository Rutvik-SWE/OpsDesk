
# OpsDesk — IT Incident & Service Request Management System

OpsDesk is a Java-based application for managing IT incidents and service requests. It aims to help employees report issues and support teams track, assign, and resolve tickets.

## Technology Stack

- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- MySQL
- Maven
- HTML, CSS and JavaScript

## Current Features

- Spring Boot project setup
- MySQL database configuration
- User and Ticket entities
- Ticket status, priority and role enums
- UserRepository and TicketRepository

## Planned Features

- Ticket creation and listing REST APIs
- Input validation and error handling
- Ticket assignment and status management
- Comments and ticket history
- Authentication and role-based authorization
- Dashboards and frontend integration
- Automated testing

## Getting Started

1. Install a compatible JDK and MySQL Server.
2. Create the `opsdesk_db` database.
3. Configure your local database credentials in `application.properties`.
4. Run `OpsdeskApplication.java` from your IDE.

Currently under development. Features will be added incrementally.
